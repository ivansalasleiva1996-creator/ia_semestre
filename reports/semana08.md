
# Semana 08 - Representaciones del Reconocimiento: Red Neuronal, BBDD y Ontología

## 1. Descripción del Desarrollo
En esta sesión se conectaron tres componentes fundamentales para la construcción de sistemas inteligentes sustentables:
1. **Red Neuronal Artificial (MLPClassifier):** Encargada del aprendizaje de patrones y la predicción numérica a partir de datos de entrada.
2. **Base de Datos Relacional (SQLite):** Encargada del almacenamiento de metadatos e historial de observaciones para auditoría y trazabilidad.
3. **Ontología (GraphML/NetworkX):** Encargada de aportar significado dentro del dominio, conectando entradas, predicciones y conceptos lógicos.
